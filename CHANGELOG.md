## [v0.8.0] - 2026-11-05

### Highlights

- Pane terminal: a plain shell below each pane's coding session, opened in the folder the session works in, shown or hidden from the pane header
- TUI Parser listens only on this machine by default and requires a token when exposed to the network; the mobile apps can send one
- Claude session history is protected from being overwritten, hook events are no longer lost, and the Claude Code hook installs safely

### Breaking

- TUI Parser listens on 127.0.0.1 by default. To reach it from another device, start it with --host 0.0.0.0 and a token (--token or TUIPARSER_TOKEN), and enter the token in the mobile app ([`d819d74`](https://github.com/plexusone/plexusone-app/commit/d819d74))

### Security

- TUI Parser required no authentication and accepted WebSocket connections from any web page, so anyone on the network or any page in the user's browser could type into tmux sessions. It now listens on this machine only by default, requires a token on any other address, rejects foreign browser origins, and rejects requests for other host names (DNS rebinding) ([`d819d74`](https://github.com/plexusone/plexusone-app/commit/d819d74))
- iOS app allows plain connections only on the local network instead of turning off App Transport Security for every connection ([`d22bbab`](https://github.com/plexusone/plexusone-app/commit/d22bbab))
- Claude Code hook command quotes the app's path with single quotes, so the shell expands nothing in it ([`26fdbe8`](https://github.com/plexusone/plexusone-app/commit/26fdbe8))

### Added

- Pane terminal: a terminal button in the pane header shows a login shell (no tmux) below the coding session, started where the Claude session started or in the tmux pane's current folder; hiding keeps it running, and each pane keeps one per session ([`7a59064`](https://github.com/plexusone/plexusone-app/commit/7a59064))
- Pane terminal height setting (Settings > General, 35% by default); drag the bar above the terminal to resize one pane, double-click it to reset ([`f04af84`](https://github.com/plexusone/plexusone-app/commit/f04af84))
- Mobile apps accept a token for TUI Parser, and the Flutter app can connect with wss:// ([`02779db`](https://github.com/plexusone/plexusone-app/commit/02779db))
- iOS app accepts a token for TUI Parser ([`995e9e2`](https://github.com/plexusone/plexusone-app/commit/995e9e2))

### Changed

- Font Size, Idle after, and Stuck after in Settings now take effect; font size changes apply to open terminals. Settings that did nothing (auto-attach, show detached sessions, restore windows on launch, cursor blink, default shell) are removed ([`a2524f2`](https://github.com/plexusone/plexusone-app/commit/a2524f2))
- Next Pane and Previous Pane also move through pane terminals ([`7a59064`](https://github.com/plexusone/plexusone-app/commit/7a59064))

### Fixed

- An unreadable Claude session log is copied aside before a new one is saved, instead of being overwritten ([`2db151b`](https://github.com/plexusone/plexusone-app/commit/2db151b))
- Session checks no longer overlap, so snapshots apply in order and a waiting notification is not posted twice ([`2db151b`](https://github.com/plexusone/plexusone-app/commit/2db151b))
- The Claude session log is saved when a session's state changes and otherwise at most once a minute, instead of every 5 seconds ([`2db151b`](https://github.com/plexusone/plexusone-app/commit/2db151b))
- Hook events are no longer lost when the events file is started afresh, and a partly written event no longer takes the next one with it ([`2db151b`](https://github.com/plexusone/plexusone-app/commit/2db151b))
- Restoring a session checks again that it is not already running, so it is not resumed twice ([`2db151b`](https://github.com/plexusone/plexusone-app/commit/2db151b))
- Failed @claude_name updates are retried ([`2db151b`](https://github.com/plexusone/plexusone-app/commit/2db151b))
- Sessions whose transcript ends in a very long line, such as a pasted image, keep their last-activity time ([`2db151b`](https://github.com/plexusone/plexusone-app/commit/2db151b))
- Installing the Claude hook keeps a symlinked ~/.claude/settings.json linked, keeps changes made to it meanwhile, and refuses to point at a temporary or disk-image copy of the app ([`26fdbe8`](https://github.com/plexusone/plexusone-app/commit/26fdbe8))
- Attaching, killing, and renaming target tmux sessions by exact name, not by prefix ([`6a181b6`](https://github.com/plexusone/plexusone-app/commit/6a181b6))
- New Session no longer offers an Agent Type choice that had no effect ([`8b2cd6b`](https://github.com/plexusone/plexusone-app/commit/8b2cd6b))
- A terminal's process is never signaled after it exits, since its PID may have been reused ([`7a59064`](https://github.com/plexusone/plexusone-app/commit/7a59064))
- TUI Parser never sends to a client after it disconnects, and logs message encoding errors ([`d819d74`](https://github.com/plexusone/plexusone-app/commit/d819d74))
- Android release builds request network access ([`566d2cc`](https://github.com/plexusone/plexusone-app/commit/566d2cc))
