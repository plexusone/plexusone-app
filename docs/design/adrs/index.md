# Architecture Decision Records

Each record captures one significant decision: the context, what was
decided, and the consequences. Records are numbered and never renumbered;
a decision that is replaced keeps its record, marked as superseded.

| ADR | Decision | Status |
|-----|----------|--------|
| [0001](0001-claude-session-end-detection.md) | Detect how a Claude Code session ended from its files plus app observation | Accepted |
| [0002](0002-tmux-mouse-mode-for-scrolling.md) | Turn on tmux mouse mode per attached session so the trackpad scrolls history | Accepted |

## Writing a record

Copy the sections of an existing record: **Context**, **Decision**,
**Consequences**, and optionally **Alternatives considered**. Name the file
`NNNN-short-title.md` with the next free number.
