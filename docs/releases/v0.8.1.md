# v0.8.1

**Release Date:** 2026-11-05

## Highlights

- **Background shell status** - Claude sessions that are running a background command, such as a dev server, show as idle with a background shell instead of `shell`

## What's Fixed

Claude Code reports the status `shell` while it waits at its prompt and a command it started, such as a local dev server, is still running. The Claude Sessions window and the pane header's tooltip showed that raw value, so a session ready for input looked like it was doing something else. They now show `idle · background shell`: the session is ready for you, and a command it started is still running.

Renaming a session from the Claude Sessions window now works in this state too, since Claude is at its prompt.

## Tests
