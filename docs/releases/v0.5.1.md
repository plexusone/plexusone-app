# v0.5.1

**Release Date:** 2026-10-07

## Highlights

- **Focus-Switch Clicks Stay Out of the Terminal** - Clicking an unfocused pane only moves focus; it can no longer select a prompt option rendered under the cursor
- **Login-Shell Sessions** - New tmux sessions start the default shell as a login shell, restoring the full PATH when the app is launched from Finder or the Dock
- **DMG Installers Are Back** - Release builds ship as `.dmg` files again, built on the `macos-26` runner
- **SwiftTerm 1.19.0** - Dictation and IME marked-text overlay improvements, and a fix for content hidden under the scroller after a font change

## What's Fixed

### Focus-Switch Clicks Stay Out of the Terminal

In a multi-pane layout, clicking an unfocused pane to bring it into focus was also delivered to SwiftTerm's `mouseDown`. With mouse reporting enabled (tmux mouse mode), SwiftTerm reports the click position to the PTY, and if a Claude Code Yes/No prompt happened to be rendered under the click, the focus-switch alone could select and execute an option the user never chose.

`TerminalContainerView` now overrides `hitTest(_:)` to claim clicks for itself while a pane lacks focus, so a click on an unfocused pane only moves focus. Panes that already have focus behave exactly as before: text selection, mouse reporting, and link clicks are unchanged.

### Login-Shell Sessions

New sessions passed the shell to tmux as an explicit command, so zsh started as a non-login shell and skipped `/etc/zprofile`. `path_helper` never ran, and an app launched from Finder or the Dock left sessions with launchd's minimal PATH, missing `/usr/local/bin` and `/etc/paths.d` entries. When no custom command is given, the shell argument is now omitted so tmux starts the default shell as a login shell, matching login terminals such as iTerm2. Custom commands pass through unchanged.

### DMG Installers Are Back

The v0.5.0 release carried zipped workflow artifacts instead of `.dmg` files because the tagged release run failed on a deprecated toolchain action before the DMG step. The release workflow now sets up Xcode directly and builds on the `macos-26` runner (GitHub retires `macos-14` on November 2, 2026), so tagged releases publish DMG installers for Universal, Apple Silicon, and Intel.

## Fixed

- Clicking an unfocused pane to give it focus no longer forwards the click into the terminal; previously the focus-switch click reached SwiftTerm's mouse reporting and could select a Claude Code prompt option rendered under the cursor ([`f04d44e`](https://github.com/plexusone/plexusone-app/commit/f04d44e))
- New tmux sessions now start the default shell as a login shell, so they get the same PATH as a login terminal such as iTerm2 (including `/usr/local/bin` and `/etc/paths.d` entries) instead of launchd's minimal PATH when the app is launched from Finder or the Dock ([`1a75908`](https://github.com/plexusone/plexusone-app/commit/1a75908))

## Build

- Bumped SwiftTerm from 1.18.0 to 1.19.0 in `apps/desktop`, picking up macOS dictation and IME marked-text overlay improvements and a fix for terminal content hidden under the scroller after a font change ([`a192269`](https://github.com/plexusone/plexusone-app/commit/a192269))

## Infrastructure

- Desktop CI path filters now match `desktop.yaml`, so changes to the workflow file itself trigger CI ([`98e0e61`](https://github.com/plexusone/plexusone-app/commit/98e0e61))
- Desktop release builds moved from the deprecated `macos-14` runner to `macos-26` ([`c7d4f99`](https://github.com/plexusone/plexusone-app/commit/c7d4f99))
